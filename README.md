[Hired](https://www.hired.co.ke) - Connecting Job Seekers with Employers in Kenya
Welcome to the Hired platform! Hired is a job board dedicated to helping job seekers connect with employers across Kenya. Our platform provides a seamless experience for candidates to discover job opportunities and for employers to find the right talent.

This project is powered by [Next.js](https://nextjs.org/), and you can find more information about its setup and deployment below.

Getting Started
To get started, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```
You can visit the live platform at Hired.co.ke.

Deploying the Project
We deploy our project via Vercel. For more information on deploying a Next.js app, check out Next.js Deployment Documentation.
